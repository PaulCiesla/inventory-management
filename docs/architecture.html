Architecture overview — tech stack, data flow, and API surface

System Architecture

Tech Stack

Frontend

Vue 3 + Vite

  • vue ^3.4 — Composition API
  • vue-router ^4.3
  • axios ^1.6 — HTTP client
  • vite ^5.2 — dev server, port 3000
  • Custom SVG charts, CSS Grid layouts
Backend

Python FastAPI

  • fastapi ≥0.110
  • uvicorn ≥0.24 — ASGI server, port 8001
  • pydantic ≥2.5 — request/response models
  • pytest / httpx — test suite (tests/backend)
  • Managed with uv
Data

In-memory mock data

  • No database
  • server/data/*.json, loaded via mock_data.py
  • inventory, orders, demand forecasts, backlog
  • spending, transactions, purchase orders
  • Filtered in-process per request

Data Flow

Filter state (Time Period, Warehouse, Category, Order Status) lives in Vue view components and flows down to a shared API client, which appends the active filters as query params on every request.

Responses land as raw refs (allOrders, inventoryItems); views derive display data via computed properties, so re-filtering never re-fetches unless the underlying dataset changes.
